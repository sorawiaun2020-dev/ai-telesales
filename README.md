# AI Telesales — ให้ AI เสียงผู้หญิงโทรขายให้ฐานลูกค้าเก่า

ระบบนี้ให้ AI ("น้องฝน" เสียงผู้หญิง พูดเป็นกันเอง) โทรหาลูกค้าเก่าทีละชุด
เสนอสินค้า ปิดการขาย เก็บที่อยู่ แล้วสรุปออเดอร์เป็นไฟล์ Excel/CSV ให้ทีมแพ็กของส่ง

```
customers.csv ──import──▶ telesales.db ──call──▶ Vapi (AI + เสียงไทย) ──▶ เบอร์ลูกค้า
                               ▲                     │
                               └───────sync──────────┘  ผล: สั่งซื้อ / โทรกลับ / ไม่สนใจ / ห้ามโทร
                                       │
                                    export ──▶ exports/orders.csv, callbacks.csv
```

- ใช้ Python 3.10+ อย่างเดียว **ไม่ต้องติดตั้ง library เพิ่ม**
- **ไม่โทรซ้ำ**: คนที่สั่งแล้ว ไม่สนใจ หรือขอไม่ให้โทร จะไม่ถูกโทรอีก ส่วนคนไม่รับสายจะโทรใหม่ทุก 24 ชม. (สูงสุด 3 ครั้ง)
- **โทรเฉพาะเวลาที่ตั้งไว้**: ค่าเริ่มต้นคือ จันทร์–เสาร์ 09:00–19:00
- **ยอดเงินในออเดอร์คำนวณจาก `products.json` เสมอ** ไม่ใช้ตัวเลขที่ AI พูด ออเดอร์ที่ข้อมูลไม่ครบจะมีคำเตือนในคอลัมน์ "ต้องตรวจสอบ"

| **ตั้งค่า** | ชื่อร้าน, ช่องทางจ่ายเงิน, ค่าส่ง, โปรโมชัน, วันและเวลาโทร, คีย์ Vapi, เสียงและโมเดล |

หัวข้อด้านล่างอธิบายการทำแต่ละขั้นแบบใช้คำสั่ง ถ้าใช้หน้า Dashboard ให้อ่านแค่ขั้นตอนที่ 1 (สมัคร Vapi) ก็พอ

## ขั้นตอนที่ 1 — สมัคร Vapi (คุณต้องทำเอง)

1. สมัครที่ **[dashboard.vapi.ai](https://dashboard.vapi.ai)** แล้วเติมเครดิต (ทดลองประมาณ $20)
2. ไปที่ **API Keys** แล้วคัดลอก **Private Key** มาใส่เป็น `VAPI_API_KEY`
3. ไปที่ **Phone Numbers** แล้วเพิ่มเบอร์โทรออก จากนั้นคัดลอก **ID** ของเบอร์มาใส่เป็น `VAPI_PHONE_NUMBER_ID`
   - **แนะนำเบอร์ไทย**: ขอ SIP trunk จากผู้ให้บริการ VoIP ในไทย แล้วเลือก "Import SIP trunk" ใน Vapi
     (ถ้าโทรจากเบอร์ต่างประเทศ ลูกค้าจะเห็นเป็นเบอร์แปลกและมักไม่รับสาย)
   - ถ้าแค่อยากลองระบบเร็ว ๆ ใช้ Twilio ก่อนได้ แต่ควรเปลี่ยนเป็นเบอร์ไทยก่อนโทรหาลูกค้าจริง

## ขั้นตอนที่ 2 — ตั้งค่าร้านและสินค้า

- **`config.json`**: ชื่อร้าน (`shop.name`), ชื่อพนักงาน AI, ช่องทางจ่ายเงิน, ค่าส่ง, โปรโมชัน, เวลาโทร, จำนวนสายต่อรอบ
- **`products.json`**: รายการสินค้า ราคา จำนวนขั้นต่ำ และจุดเด่น ใส่ `"featured": true` กับสินค้าที่อยากให้ AI เสนอก่อน
  **เปลี่ยนสินค้าเมื่อไรก็ได้** แก้เสร็จแล้วรัน `python main.py sync-assistant` หนึ่งครั้ง

ดูบทพูดที่ AI จะใช้ได้ด้วยคำสั่ง `python main.py show-prompt`

## ขั้นตอนที่ 3 — สร้าง AI และโทรทดสอบหาตัวเอง

```bash
cp .env.example .env              # ใส่ VAPI_API_KEY, VAPI_PHONE_NUMBER_ID
set -a; . ./.env; set +a          # โหลดค่าเข้า shell

python main.py sync-assistant     # ครั้งแรกจะได้ ID มา -> ใส่ VAPI_ASSISTANT_ID ใน .env แล้วโหลดใหม่
python main.py test-call 08xxxxxxxx --name สมชาย
```

ฟังเสียงและดูบทสนทนาย้อนหลังได้ที่ dashboard.vapi.ai → **Call Logs**
**ควรโทรทดสอบ 10–20 สาย** และลองเป็นลูกค้าหลายแบบ (ตกลงซื้อ, ต่อราคา, ไม่สนใจ, บอกว่าไม่ต้องโทรมาอีก)
แล้วปรับ `config.json` / `products.json` จนพอใจ

> ถ้าเสียงหรือการฟังภาษาไทยยังไม่ดี ลองเปลี่ยน `assistant.voice_provider` / `voice_id` / `transcriber_provider`
> เป็นตัวที่ Vapi มีให้เลือก (เช่นเสียงไทยของ ElevenLabs) แล้วรัน `sync-assistant` ใหม่
> ถ้า Vapi ไม่รู้จักชื่อ `assistant.model` ให้เปลี่ยนเป็นโมเดลที่ Vapi แสดงในหน้า Assistant

## ขั้นตอนที่ 4 — นำเข้ารายชื่อลูกค้า

ใช้ไฟล์ Excel (.xlsx) ได้เลย หรือ CSV ก็ได้ โดยคอลัมน์ต้องมีอย่างน้อย `ชื่อ` และ `เบอร์โทร`
(คอลัมน์ `สินค้าที่เคยซื้อ` และ `หมายเหตุ` ใส่หรือไม่ใส่ก็ได้ AI จะใช้ทักทายให้เป็นส่วนตัวขึ้น) ดูตัวอย่างได้ที่ `customers.example.csv`

```bash
python main.py import customers.csv
```

เบอร์ทุกรูปแบบใช้ได้ (`081-234-5678`, `66812345678` หรือแบบที่ Excel ตัด 0 หน้า)
นำเข้าซ้ำได้ ระบบจะไม่สร้างรายชื่อซ้ำ และ**ไม่รีเซ็ตสถานะคนที่โทรไปแล้ว**

> ⚠️ ไฟล์รายชื่อและ `telesales.db` เป็นข้อมูลส่วนตัวของลูกค้า ระบบตั้งไว้ไม่ให้ขึ้น Git แล้ว ห้าม commit เอง

## ขั้นตอนที่ 5 — เริ่มโทร (เริ่มจากน้อย ๆ ก่อน)

```bash
python main.py call --dry-run --limit 50   # ดูว่าจะโทรหาใครบ้าง ยังไม่โทรจริง
python main.py call --limit 20             # โทรจริง 20 สาย
python main.py sync                        # หลังวางสายแล้ว ดึงผลมาเก็บ
python main.py report                      # สรุปผล + อัตราปิดการขาย + ค่าใช้จ่าย
python main.py export                      # สร้าง exports/orders.csv และ exports/callbacks.csv
```

เมื่อผลดีแล้ว ปล่อยให้ระบบทำงานเองต่อเนื่อง (บนคอมหรือ VPS ที่เปิดทิ้งไว้):

```bash
python main.py run --loop --interval 5     # ทุก 5 นาที: ดึงผล + โทรชุดใหม่ (เฉพาะในเวลาโทร)
```

ถ้าลูกค้าแจ้งผ่านช่องทางอื่นว่าไม่ต้องโทรมาอีก ใช้คำสั่ง `python main.py dnc 0812345678`

## หลังได้ออเดอร์

`exports/orders.csv` มีข้อมูลสินค้า ยอดรวม ที่อยู่ วิธีชำระเงิน สรุปสาย และลิงก์ไฟล์เสียง
**ควรให้แอดมินส่ง SMS/ไลน์ยืนยันออเดอร์ก่อนส่งของ** (AI บอกลูกค้าไว้แล้วว่าจะมีข้อความยืนยันตามมา)
และถ้าคอลัมน์ "ต้องตรวจสอบ" มีข้อความ ให้เปิดฟังไฟล์เสียงของสายนั้นก่อน

## ค่าใช้จ่าย (ประมาณการ)

ค่าบริการของ Vapi (AI + เสียง + แปลงเสียงเป็นข้อความ) บวกค่าโทรศัพท์ รวมประมาณ **$0.10–0.30 ต่อนาที**
ถ้าสายหนึ่งยาว 2–3 นาที โทร 10,000 สายจะใช้ประมาณ $2,000–9,000 ค่าใช้จ่ายจริงดูได้จากคำสั่ง `report`
ราคาเปลี่ยนได้ ให้ตรวจราคาล่าสุดใน Vapi ก่อนเริ่มโทรจำนวนมาก
**แนะนำให้ทดลอง 200–500 สายก่อน** แล้วดูอัตราปิดการขายว่าคุ้มหรือไม่
